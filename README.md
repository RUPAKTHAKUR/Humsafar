# Humsafar (हमसफ़र) — India-Wide Shared Cab Platform

**Humsafar** ("Travel Companion" in Hindi) is an India-wide shared cab and ride-pooling platform designed to provide affordable, transparent, and eco-friendly urban mobility across Indian metropolitan corridors. Unlike traditional ride aggregators that charge flat per-head fares, Humsafar splits fares **segment-by-segment** based on the exact kilometers you are in the vehicle.

---

## 🚀 Key Highlights & Architectural Features

### 1. Fair Segment-by-Segment Pricing Engine (`src/lib/pricing.ts`)
- **Dynamic Segment Splitting**: The route is cut into individual segments at every pickup and drop-off waypoint.
- **Fair Passenger Division**: For each segment, the vehicle running cost (`₹11/km` for 4-seater Mini, `₹14/km` for 7-seater SUV) is divided equally among only the passengers present in the cab on that segment.
- **Detour Transparency**: Any extra kilometers generated by picking up or dropping off a specific passenger are billed strictly to that rider, preventing other passengers from subsidizing detours.
- **Transparent Charges**: Base fare (shared) + ₹9 booking fee per rider + clear savings breakdown against solo taxis.

### 3. Five-Phase Ride Booking Journey (`src/components/BookingFlow.tsx`)
1. **Route Selection**:
   - Geolocation auto-detection with *"Use Current Location"* nearest-place matching.
   - Popular corridor quick-select with instant distance and travel time calculation.
2. **Cab & Mode Selection**:
   - Vehicle choices: 4-Seater Mini (up to 3 pool seats) and 7-Seater SUV (up to 6 pool seats).
   - Mode: **Share** (pool with others) or **Solo** (exclusive whole-cab booking).
   - Safety Filter: **Women-Only Pool** mode with verified female riders and safety protocols.
3. **Pool Matching**:
   - Simulated corridor matching algorithm finding nearby riders heading along the same trajectory.
   - Interactive `PoolCard` with passenger profiles, pickup/drop points, and transparent cost breakdown.
   - Gantt-style `PoolTimeline` visualization displaying each rider's road segment coverage.
4. **Live Ride Simulation**:
   - Simulated real-time GPS progression with arrival countdown.
   - Assigned driver card with rating, vehicle plate number, and phone connect button.
   - 4-digit security OTP handshake.
   - Emergency SOS one-tap safety alert.
5. **Trip Receipt & Rating**:
   - Transparent digital invoice showing total savings vs solo cab.
   - Interactive 5-star rating system with instant feedback collection.

### 4. Interactive Fare Calculator (`src/components/FareCalculator.tsx`)
- Direct visual comparison between Solo Cab and Pooled Ride.
- Interactive pool size slider showing per-person savings in real-time.
- Worked mathematical examples demonstrating segment splits.

### 5. Three Distinct Role-Based Dashboards
- **Rider Dashboard (`/dashboard/user`)**: Quick-book triggers, recent trip history with status badges, favorite routes, profile toggles, and notification center.
- **Driver Dashboard (`/dashboard/driver`)**: Online/offline availability switch, live incoming ride requests (Accept/Decline), GPS navigation assist, scheduled pickups list, and daily/weekly earnings tracker.
- **Owner & Fleet Dashboard (`/dashboard/owner`)**:
  - 6 Key Performance Indicators (Total Bookings, Gross Revenue, Active Drivers, Average Savings, Women-Only Trips, Completion Rate).
  - Pure SVG 7-Day Revenue Velocity line/area chart.
  - SVG City Volume distribution bar chart.
  - Corridor density analytics and safety compliance metrics.
  - Searchable and filterable bookings table.
  - One-click browser CSV export of all trip logs.

## 🏃 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the Turbopack development server
npm run dev

# 3. Create a production build
npm run build

# 4. Start production server
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser:
- Landing Page: `/`
- Cab Booking: `/book`
- Fare Calculator: `/fare`
- Rider Dashboard: `/dashboard/user`
- Driver Dashboard: `/dashboard/driver`
- Fleet Owner Console: `/dashboard/owner`
